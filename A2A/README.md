
# COS30019 - Assignment 2A

This project implements six tree-based search algorithms in Python for a route-finding problem.

## Requirements
- Python 3
- No additional libraries required

## How to Run

Open the project folder in Command Prompt or VS Code Terminal.

Run an algorithm:

    python search.py <filename> <method>

Example:

    python search.py tests/multiple_destinations.txt BFS

Supported methods: DFS, BFS, GBFS, AS, CUS1, CUS2.

## Testing

To run all test cases:

    python test_suite.py

The program includes 17 test cases, with 102 total executions across six algorithms.
